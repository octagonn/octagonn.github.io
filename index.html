Homelab

Five machines I run like production.

Two Proxmox hosts, a Windows Server, a Raspberry Pi, and an on-demand GPU worker run about thirty self-hosted services. I migrated the workloads off Hyper-V, put everything behind a reverse proxy with private DNS, and reach it remotely through a Tailscale subnet router.

Scale
5 nodes, 3 VMs, ~30 services
Hardware
15U cabinet, two OptiPlex 7050s, Raspberry Pi 4, 8-port PoE switch, 10-outlet PDU
Network
Nginx reverse proxy, AdGuard DNS, Tailscale split DNS, default-deny firewalls
Resilience
Nightly VM backups, uptime monitoring, self-healing watchdogs
Incidents
Root-caused a port 443 boot race between Tailscale and Nginx and a subnet routing loop
